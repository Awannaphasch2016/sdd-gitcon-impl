# Constitution

- PHP 8.2 or newer.
- One Dockerfile at the repository root. The image serves HTTP on port 80 and needs no network access at runtime.
- No external services: no database server, no mail, no CAPTCHA, no analytics, no CDN.
- SPEC.md is immutable. Never edit it after it is written.
- Tests inside the repository are optional.
- Do not search for or copy an existing implementation of this site.
